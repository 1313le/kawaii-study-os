03

这套站怎么造的

COLOPHON / 技术栈与设计

HTML CSS Vanilla JS Markdown marked Mermaid KaTeX highlight.js GitHub Pages

DESIGN / 双主题皮肤：PIXEL 是深紫夜色、像素字体、CRT 扫描线与星尘粒子；LINE 是暖白纸面、Bricolage Grotesque 大标题与可交互的量化线场。所有动效都可以一键关闭，并尊重系统的“减少动态效果”设置。
BUILD / 纯静态站点，无后端、无追踪。依赖与字体全部本地化，构建脚本把 Markdown 编译成可直接检索的 HTML 索引。
